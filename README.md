# BOOX PICCO 책 목록 한글 표시 펌웨어

BOOX PICCO의 **책 목록에서 한글 제목이 네모(□)로 표시되는 문제**를 해결하기 위한 비공식 수정 펌웨어입니다.

BOOX 기본 펌웨어에서는 한글 폰트를 추가하면 **책 본문은 정상적으로 표시**되지만, **책 목록의 한글 제목은 네모로 표시**되는 문제가 있었습니다. 이 파일은 그 문제를 해결하기 위해 ChatGPT 웹 버전의 도움을 받아 기본 펌웨어를 수정한 결과물입니다. 배포자는 실제 PICCO에 설치하여 사용 중입니다.

책 목록의 한글 제목 표시에 **나눔고딕(Nanum Gothic) 글꼴**을 적용했습니다.

이 저장소에서 다루는 기능은 **책 목록의 한글 제목 표시**입니다. 책 본문에 사용할 한글 폰트는 별도로 추가해야 합니다.

## PICCO에 설치하기

### 1. 준비

- PICCO를 충분히 충전하고 책, 폰트 등 필요한 파일을 백업합니다.
- **데이터 전송이 가능한 USB 케이블**과 PC를 준비합니다.
- PC의 최신 **Chrome 또는 Edge**를 사용합니다. 설치 페이지는 Web Serial API를 사용합니다.
- 아래 절차는 BOOX 기본 파티션 구성을 사용하는 PICCO를 대상으로 합니다. 다른 기기에는 설치하지 마세요.

> 이 파일은 앱 영역만 담은 이미지입니다. **Full flash(전체 쓰기) 모드에 사용하지 마세요.** 전체 플래시 삭제나 파티션 변경도 필요하지 않습니다. 비공식 펌웨어 설치에는 부팅 실패 등의 위험이 있으므로 설치 중 케이블을 뽑거나 전원을 끄지 마세요.

### 2. 공식 설치 페이지 열기

PC에서 **[BOOX Tiles — Firmware Flash](https://www.booxtiles.com/firmware)**를 엽니다.

`Operation mode`에서 **OTA update**를 선택합니다. 이 페이지의 OTA update는 USB를 통해 **앱 파티션만 갱신**하는 기능입니다.

### 3. 수정 펌웨어 선택

`Drag firmware here` 영역에 이 저장소에서 받은 **`PICCO_1.05_2959_Korean_NanumGothic.bin`**을 드래그하거나, 해당 영역을 눌러 파일을 선택합니다.

선택된 파일 이름이 위 이름과 같은지 확인하세요. 페이지의 공식 펌웨어 목록에서 다른 버전을 다운로드하면 이 저장소의 한글 수정 파일 대신 공식 파일을 설치하게 됩니다.

### 4. PICCO 연결 및 Recovery 진입

1. PICCO를 USB 케이블로 PC에 연결합니다.
2. **전원 버튼 + 위쪽 버튼(Power + Up)을 동시에 10초 이상** 눌러 **Recovery 화면**이 나타날 때까지 기다립니다.
3. PC의 설치 페이지로 돌아갑니다.

이 버튼 조합은 2026-11-19에 확인한 공식 설치 페이지 안내 기준입니다. 기기나 페이지의 안내가 달라졌다면 해당 안내를 먼저 확인하세요.

### 5. 앱 펌웨어 쓰기

1. **Connect and update app**을 누릅니다.
2. 브라우저의 포트 선택 창에서 PICCO에 해당하는 포트를 선택하고 연결합니다. 이름은 `USB JTAG/serial debug unit`, `usbmodem` 등으로 표시될 수 있습니다.
3. 포트를 다시 선택하라는 안내가 나오면 페이지 안내에 따라 버튼을 다시 눌러 해당 기기를 선택합니다.
4. 설치 완료 메시지(**Update complete**)가 나올 때까지 기다립니다.

공식 도구는 기기의 파티션 테이블과 파일 크기를 검사한 후 앱 영역을 기록합니다. **파티션 불일치, 모델 불일치, 파일 크기 초과 오류가 나오면 중단**하고 원인을 확인하세요. 오류를 피하려고 Full flash로 전환하지 마세요.

### 6. 재시작 및 확인

1. 설치가 끝난 뒤 기기가 Recovery 화면에 머물러 있으면 Recovery 메뉴의 **Restart**를 선택합니다.
2. 정상 부팅 후 **책 목록에서 한글 제목이 표시되는지** 확인합니다.
3. 책을 열어 본문도 확인합니다. 본문용 한글 폰트가 필요하면 별도로 추가하고 선택하세요.

## 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| 브라우저에서 설치 기능을 지원하지 않음 | PC용 Chrome/Edge로 HTTPS 설치 페이지에 접속했는지 확인 |
| 포트가 나타나지 않음 | 데이터 케이블인지 확인하고 다른 USB 포트 사용, Recovery 화면 확인 |
| 포트에 연결할 수 없음 | 같은 기기를 사용하는 다른 브라우저 탭, BOOX 앱, 시리얼 프로그램 종료 후 재시도 |
| 잘못된 이미지 또는 Full flash 관련 오류 | OTA update 모드와 선택한 파일 이름을 확인하고 파일을 다시 다운로드 |
| 파티션 또는 모델 불일치 | 설치 중단. 다른 커스텀 펌웨어 등으로 구성이 바뀌었다면 BOOX의 해당 기기 복구 안내 확인 |
| 설치 후 Recovery 화면에 머무름 | 설치 완료를 확인한 뒤 Recovery 메뉴에서 Restart 선택 |

기본 펌웨어로 돌아가려면 [BOOX Tiles 공식 설치 페이지](https://www.booxtiles.com/firmware)의 PICCO용 공식 펌웨어를 사용하세요. 정상적인 기본 파티션 구성을 유지한 경우 OTA update 방식으로 공식 앱 펌웨어를 다시 설치할 수 있습니다. 부팅 불가나 파티션 변경 상태의 복구는 이 파일로 보장하지 않습니다.

공식 펌웨어로 다시 업데이트하면 이 파일의 한글 수정 사항은 덮어써질 수 있습니다.
